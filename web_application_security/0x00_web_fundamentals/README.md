This project explores the core architecture of the World Wide Web. From the historical evolution of Web versions to the intricate communication between Front-End and Back-End, this repository covers the essential knowledge required to understand how modern web applications are built, secured, and scaled.

## 🎯 Learning Objectives

At the end of this project, you are expected to be able to explain the following concepts clearly without the help of a search engine:

### The Web & Evolution

* How the **Web** actually works.
* Concrete examples of **Web Applications**.
* The evolution from **Web 1.0** (Static) to **Web 2.0** (Social/Interactive) to **Web 3.0** (Decentralized/Semantic).
* **PWA** (Progressive Web Applications) and their benefits.

### Data & Communication

* How the **Front-End** communicates with the **Back-End**.
* **Stateful vs Stateless**: Understanding the difference in session management.
* **Structured vs Unstructured Data**: Identifying different data storage formats.

### Security

* Common **Web Application Security Risks** (OWASP).
* The purpose and function of **Bug Bounty Programs**.

## 🛠️ Key Concepts Overview

| Concept | Description |
| --- | --- |
| **PWA** | Web apps that use modern web capabilities to deliver an app-like experience to users. |
| **Stateless** | A communication protocol in which the receiver does not retain session information. |
| **Structured Data** | Highly organized data that fits into fixed fields (SQL). |
| **CORS** | A system that allows restricted resources on a web page to be requested from another domain. |
